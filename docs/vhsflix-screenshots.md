## Reglas para preparar capturas

1. Exportar en WebP cuando se integren en el portfolio.
2. No mostrar correos, nombres, tokens, identificadores ni datos reales.
3. Usar cuentas y comentarios ficticios.
4. No mostrar claves de TMDB, YouTube, Resend, JWT ni URLs privadas de base de datos.
5. Mantener capturas limpias, sin overlays del navegador ni barras innecesarias.
6. Optimizar las imagenes antes de incorporarlas al repositorio.
7. Mantener una proporcion estable, preferiblemente 16:9 para pantallas web.
8. Documentar cualquier nueva captura en este archivo antes de usarla en el caso de estudio.

## Assets que no deben confundirse con capturas finales

- `logo.jpeg`, `logo1.png` y `vite.svg` son assets de marca o plantilla, no capturas de funcionalidad.
- Las capturas actuales del README sirven como evidencia, pero pueden sustituirse por versiones optimizadas y anonimizadas antes de integrarlas en el portfolio.
