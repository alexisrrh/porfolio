## Instrucciones

1. Exportar las capturas en formato WebP.
2. Evitar datos personales reales.
3. Usar capturas limpias, legibles y representativas del flujo.
4. Mantener un ancho razonable para no aumentar innecesariamente el peso del repositorio.
5. Optimizar cada imagen antes de añadirla.
6. Actualizar la configuración de imágenes del caso de estudio cuando exista cada archivo.
